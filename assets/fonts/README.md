# Fonts

The cards in this directory embed a **subset** of [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono)
(only the glyphs the cards actually draw) as inline WOFF2, so they render
identically everywhere — an SVG served through GitHub's image proxy cannot
fetch an external font.

JetBrains Mono is licensed under the SIL Open Font License 1.1; the full
licence text is in `JetBrainsMono-OFL.txt`. JetBrains Mono is a trademark of
JetBrains s.r.o. The same font is used for `../launch.gif`, which is
rasterised rather than embedded.
